# Statistics & Computer Science, BSLAS — Major Requirements

- Catalog year: 2026–2027
- Official source: [Statistics & Computer Science, BSLAS — Degree Requirements](https://catalog.illinois.edu/undergraduate/eng_las/statistics-computer-science-bslas/#degreerequirementstext)

## Required Major Courses

### Computer science foundation

| Course | Hours |
| :-- | --: |
| CS 124 — Introduction to Computer Science I | 3 |
| CS 128 — Introduction to Computer Science II | 3 |
| CS 173 — Discrete Structures | 3 |
| CS 222 — Software Design Lab | 1 |
| CS 225 — Data Structures | 4 |
| CS 357 — Numerical Methods I | 3 |
| CS 374 — Introduction to Algorithms & Models of Computation | 4 |
| CS 421 — Programming Languages & Compilers | 3 |

Complete **one entire computer systems alternative (8–11 hours)**:

- **Alternative A:** CS 233 — Computer Architecture **and** CS 341 — System Programming.
- **Alternative B:** CS 340 — Introduction to Computer Systems **and two** 400-level CS courses numbered above CS 403, excluding CS 421 and CS 491. These two courses must be distinct from all other courses used for program requirements or options.

### Probability and statistics foundation

Choose one introductory course for **3–4 hours**:

- STAT 107 — Data Science Discovery
- STAT 200 — Statistical Analysis
- STAT 212 — Biostatistics

Also complete all of the following. Hours below retain the degree-requirement table's credit entries.

| Course | Hours |
| :-- | --: |
| STAT 400 — Statistics and Probability I | 4 |
| STAT 410 — Statistics and Probability II | 3 or 4 |
| STAT 425 — Statistical Modeling I | 3 or 4 |
| STAT 426 — Statistical Modeling II | 3 or 4 |

## Required Preparatory and Supporting Coursework

Calculus through MATH 241 — Calculus III: **11–12 hours**.

Choose one linear algebra course for **3 hours**:

- MATH 257 — Linear Algebra with Computational Applications
- MATH 415 — Applied Linear Algebra

- STAT 432 — Basics of Statistical Learning

Choose one:

- CS 410 — Text Information Systems

- CS 446 — Machine Learning
- CS 481 — Advanced Topics in Stochastic Processes & Applications
